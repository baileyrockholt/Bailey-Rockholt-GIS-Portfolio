California Crop Suitability Tool

A transparent scoring tool for exploring how environmental inputs and regional preferences affect crop rankings.

Download Python sourceView source on GitHub ↗

What the tool does

The application offers 12 county presets or a custom site, evaluates 15 crop profiles, ranks results, explains individual factor scores, and exports a CSV. The implementation uses Python’s standard library, including csv, math, and datetime.

Programming demonstrated

Structured dictionaries · Reusable functions · Menu-driven input · Weighted scoring · Sorting · Factor explanations · CSV export

Scoring workflow

From site inputs to ranked results

  1. Select a county or enter custom site values for soil pH, rainfall, average temperature, and elevation.
  2. Score each environmental factor against a crop’s preferred range. Scores decline with distance from the range midpoint.
  3. Combine factor scores using pH 30%, rainfall 20%, temperature 35%, and elevation 15%.
  4. Combine the environmental score (88%) with a regional-preference score (12%), then sort crops and identify each crop’s lowest-scoring factor.
  5. Inspect results in the terminal or export the ranking and factor scores to CSV.

Run the original tool

Download the Python file and run it with Python 3:

python Rockholt_California_Crop_Suitability_Tool.py

No third-party packages are required. Run from a folder where you want the exported CSV files saved.

Review and checks

Checks passed for module import, preset and crop counts, normalized environmental weights, score bounds for finite inputs, range-score behavior, limiting-factor labels, and basic menu paths. The downloadable sample was generated from this implementation.

Read implementation notes and limitations

Scope and next steps

This is an educational programming prototype. County values, crop ranges, weights, and classifications are hard-coded assumptions without citations in the supplied script. The tool does not ingest GIS layers or live soil and climate data, and its score is not a probability, yield estimate, or validated agronomic assessment.

Water demand is descriptive rather than scored. A future version could validate inputs, cite authoritative datasets, support GIS-derived site attributes, and compare its rankings with independent evidence.
